# 🍅 Tomato — Food Ordering Landing Page

Live Demo: `https://spiffy-quokka-1c9b9e.netlify.app/`

Tomato is a clean, responsive food-ordering landing page built to showcase a modern restaurant UI with smooth user flow and visually grouped food categories. A simple, polished front-end project ideal for portfolio display.

## ✨ Features

- Hero section with tagline + “View Menu” CTA
- Category-based food menu (Salad, Rolls, Desserts, Sandwich, Cake, Pure Veg, Pasta, Noodles)
- “Top Dishes Near You” grid with dish name, short info, and price in ₹
- Smooth single-page navigation (Home / Menu / Mobile App / Contact)
- Mobile app promotional section for cross-platform branding
- Footer with company links + email and phone contact

## 🛠 Tech Stack

- React (CRA)
- HTML, CSS, JavaScript
- Fully responsive UI
